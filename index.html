Privacy Policy

Last updated September 18, 2026

Data we store

Account users store their email through Supabase Authentication plus the tasks, habits, focus sessions and reviews they choose to save. Local mode stores planner data only in the current browser.

How we use it

We use this information to provide and sync the planner. We do not sell your personal data.

Security

Cloud application tables use row-level security so authenticated users can access only their own records.

Providers

Supabase provides authentication and database services. GitHub Pages hosts the frontend.
